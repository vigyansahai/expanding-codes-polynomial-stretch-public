Fix a rational parameter $0<\theta<1/2$, and put $d=\mathrm{dimension}(\theta)$ and $k=\mathrm{arity}(\theta)$. We construct one finite transition table, depending on $\theta$ but independent of the input size, which samples exactly the prescribed distribution of generator matrices. Its running time and the number of unbiased random bits supplied are bounded by a common polynomial in $n$.

The finite field is represented by binary coefficient vectors modulo a monic irreducible polynomial. The foundational definitions specify the field and its ordering. The proof implements finding the modulus, arithmetic, size parameters, and output on actual work tapes. Each bounded search and loop has an execution invariant and a step bound; polynomial bounds concern these executions rather than an abstract arithmetic oracle.

For each layer and each value of its first linear form, the program reads the coefficient bits of two independent linear forms. It also reads the entire independently uniform hash table for that layer. Because the field size and the number of buckets are powers of two, fixed blocks of unbiased bits give exactly uniform coefficients and hash values. The equivalences between bit tables and these finite choices prove equality with the canonical sampling law. Extra random bits in the common polynomial envelope are unused; restricting a uniform tape to the needed prefix preserves that law.

The row-writing loop evaluates the three linear coordinates of each row, looks up its hash bucket, and writes the corresponding binary matrix row, including the padded zero columns. The execution proof establishes the complete output string, not only its individual entries. The invariants for field arithmetic, odometers, lookup tables, and row output compose to the theorem `sampler_source`; its clock has a proved polynomial bound for fixed $d,k$.

Finally, the verified finite-program compiler produces an `NKtLB.Machine`. Its simulation theorem transfers halting, output, and the polynomial clock to the canonical machine model. The bridge `binary_sampler_of_source` chooses one polynomial envelope for runtime and random-tape length and proves both clauses of `SamplerImplementation`: every supplied tape produces a matrix, and each matrix has precisely its prescribed probability.
